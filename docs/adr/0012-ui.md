# ADR-0012: UI

- Status: Accepted (extended by ADR-0044, ADR-0047, ADR-0049)
- Date: Oct 9, 2026
- Spec: D12
- Deviation from the recipe: Not covered by the recipe (UI).

## Decision

native scrollback, plus a `/unii` TUI popup with a status line (ON/OFF, pending compactions, view size, last cache read/write), a View tab (rendered view with ids) and an Archive tab (browse the log and zoom).
